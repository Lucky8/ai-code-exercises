Part 4: FastAPI To-Do List Application

The accompanying `todo_api.py` file implements a small in-memory to-do API. It follows the
validation, error-handling, modularity, and automatic documentation patterns from Parts 1-3.

FILES:

use-cases\task-manager\python\Exercises\Learn a new framework, library or API\Exercise Getting Started with FastAPI\test_todo_api.py

1. Features

- Create a to-do item with a required title and due date plus an optional description.
- List all items with an optional `status` query filter: `pending` or `completed`.
- Mark an item as completed.
- Delete an item.
- Validate request bodies and return FastAPI's standard `422` validation response for invalid input.
- Return `404 Not Found` when completion or deletion targets an item that does not exist.
- Generate OpenAPI documentation automatically at `/docs`, `/redoc`, and `/openapi.json`.

The example uses an in-memory dictionary instead of a database so it is easy to run and understand.
All data is lost when the process stops. A production version should replace this store with a
database and repository layer.

2. Install and run

Open a terminal in this directory and create a virtual environment:

	python -m venv .venv
	.venv\Scripts\Activate.ps1
	pip install -r requirements.txt

Start the development server:

	uvicorn todo_api:app --reload

Open `http://127.0.0.1:8000/docs` to try the endpoints in Swagger UI. ReDoc is available at
`http://127.0.0.1:8000/redoc`.

3. API endpoints

Create an item:

	POST /todos

	{
		"title": "Learn FastAPI",
		"description": "Build a small API",
		"due_date": "2026-09-30"
	}

List all items or filter by status:

	GET /todos
	GET /todos?status=pending
	GET /todos?status=completed

Mark an item as completed:

	PATCH /todos/{todo_id}/complete

Delete an item:

	DELETE /todos/{todo_id}

The create endpoint returns `201 Created`. Successful list and completion requests return `200 OK`.
Successful deletion returns `204 No Content`. Invalid bodies or invalid status values return `422`,
and unknown item IDs return `404`.

4. Run the tests

Run the focused test suite from this directory:

	python -m pytest test_todo_api.py -v

The tests verify creation, validation, filtering, completion, deletion, not-found errors, and the
OpenAPI document. The application can also be tested without starting Uvicorn because FastAPI's
`TestClient` sends requests directly to the application object.
